# Historical project decisions

Append-only history. Early claims that a reviewer guarantees quality were hypotheses and are not established; current validation takes precedence.

[2026-07-14] DECISION: Started ACENET — a model-orchestration harness where frontier models plan and verify while open-weight models execute, targeting 60-85% token-cost reduction at frontier quality. Positioned as a core ACE differentiator: engineered token economics vs competitors' frontier-API pass-through. | REASONING: First principles — token prices differ 10-50x between frontier and open-weight models; 80-90% of agentic tokens are execution not judgment; quality is set by the checker not the doer (frontier plan + verify + escalation floor guarantees quality). KISS — v1 is one pipeline (plan→execute→verify→escalate→ledger), one workload (deal-document extraction, objective acceptance criteria), TypeScript + Vercel AI SDK/Gateway, no self-hosting, no framework, no UI. The per-run cost ledger with frontier-only counterfactual is the sales asset. | CONTEXT: Plan at projects/acenet/plan.md. Phases: 0 spec (wk of Jul 14) → 1 MVP loop (Jul 31) → 2 benchmark (early Aug) → 3 harden (Aug) → 4 productize (Sep, only after passing benchmark — sequenced to not compete with the August £10k push). Health metric: escalation rate <20%. ACENET ships inside T2/T3 engagements, not a separate SKU in v1. Code will live in its own acenet repo per vault rule.

[2026-08-17] DECISION: Wrote concept pages for the two founding operating principles — wiki/concepts/first-principles-thinking.md and wiki/concepts/kiss.md — completing the set so all five principles have full treatments. Grounded them in the vault's own decision history rather than in any external source. | REASONING: The three philosophy ingests earlier today gave principles 3, 4 and 5 full concept pages, leaving ACE's own two with only their CLAUDE.md definitions and a dangling [[first-principles-thinking]] stub. That asymmetry implied the borrowed principles were better specified than the native ones, which is backwards — first principles and KISS have governed every decision since 2026-06-25 and have a far longer application record in this vault than Munger, Naval or Thiel. Using the decision log as the source instead of a book is the KISS answer: the evidence for how ACE actually reasons is already written down, dated, and specific. | CONTEXT: Both pages tabulate real worked examples with dates. First principles: Logan Room repricing (2026-08-11), weighted-pipeline retirement (2026-08-10), vault migration, Partner Program revenue share, ACENET model-tiering, churn analysis. KISS: MAM/MEM/MDM → Attract/Convert/Deliver, the weighted-pipeline cut, "two roles one formula", one price per tier, Karpathy vault pattern. Failure modes documented for the first time on both — Chesterton's Fence, inherited-assumptions vs inherited-knowledge, physics envy and motivated decomposition for principle 1; avoidance-dressed-as-simplicity, simple-vs-easy, premature simplification (Gall) and collapsed time horizons for principle 2. Retained the founding entry's own anchors: Aristotle plus Musk's battery decomposition, and Kelly Johnson's Skunk Works repairability criterion, with the note that "stupid" describes the conditions under which things break, not the person. Non-obvious finding recorded on the KISS page: across every ACE example the simpler version was also the more honest one, because complexity was concealing an unmade decision, an invented number, or a name that would not say what it meant — which is the mechanism behind the 2026-06-25 diagnostic that complication is a signal to return to first principles. KISS is deliberately the shortest concept page in the vault and says so. Swept: CLAUDE.md, wiki/concepts/operating-philosophy.md, wiki/index.md.
