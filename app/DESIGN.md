# ACENET workbench: design lock

Source: ACE's existing Oxide reference lock and canonical ace-tokens.css, verified
from projects/ace-rebrand. Refero MCP is unavailable in this session; the existing
approved target plus Refero's bundled craft-details guide govern this direct build.

Designing a hosted and local web workbench for Hamza to send briefs through the Astra/body harness.
Primary action: submit one task in a centered ChatGPT-style text composer. Models and limits stay collapsed. The run inspector exposes the Brain → Body → Review route,
with actual call progress below it. No invented health, savings or activity metrics.

| Decision | Source | Role |
|---|---|---|
| Void / carbon / slate structure | ACE canonical tokens | Canvas, panels, hairlines |
| Green, teal controls | Oxide reference lock | Active choice, focus, primary action |
| Inter 400; IBM Plex Mono microtype | ACE tokens | Body/headings; labels and data |
| Square boundaries, no shadows | Oxide reference lock | App chrome and controls |
| History rail + compose/inspect workspace | User task and persisted harness runs | Select previous work, submit new work |
| Brain/body/review sequence | Existing harness code | Communicate real execution flow |
| Labelled controls, keyboard focus, 44px touch targets | Refero craft-details | Accessible operation |
| Clear unaccepted/failed state, unknown cost remains unknown | Harness contract | Preserve evidence boundaries |

No illustrative hero, decorative gradients or promotional claims. Use the existing ACE
logomark. Local server binds to loopback and serves only app assets and explicit run data.

Fonts use the canonical Inter / IBM Plex Mono stacks with system fallbacks; downloaded fonts were excluded pending license retrieval.
